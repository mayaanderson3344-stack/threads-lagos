# THREADS LAGOS
Modern premium fashion storefront and seller dashboard demo.

- Open index.html for the customer storefront.
- Open admin.html for the seller demo panel.
- Demo products, cart, checkout and order status use browser localStorage.
- This repository is public because GitHub Pages hosting on the free plan uses public repositories.

IMPORTANT: This is a front-end demo only. No real payments are collected, no WhatsApp/email notifications are sent, and seller data is not protected by login yet. Do not use it for real customer transactions until Supabase, authentication, payment verification, messaging and order tracking have been implemented and tested.
